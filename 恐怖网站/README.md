# 恐怖网站项目

这是一个基于HTML、CSS和JavaScript构建的恐怖体验网站。

## 项目结构

```
恐怖网站/
├── index.html       # 主页
├── disclaimer.html  # 免责声明页面
├── styles.css       # CSS样式文件
├── script.js        # JavaScript交互文件
└── README.md        # 项目说明文件
```

## 功能特点

- 恐怖主题的视觉设计
- 交互式开始按钮，点击后触发恐怖效果
- 随机出现的恐怖元素（幽灵、血滴等）
- 响应式设计，适配不同屏幕尺寸
- 详细的免责声明页面

## 使用方法

1. 使用Visual Studio Code打开项目文件夹
2. 安装Live Server扩展（如果尚未安装）
3. 在index.html文件上右键点击，选择"Open with Live Server"
4. 在浏览器中体验恐怖网站

## 自定义开发

### 添加音效

目前JavaScript代码中有音效相关的代码框架，但没有实际的音频文件。您可以添加以下音效文件到项目中：
- `sounds/click.mp3` - 按钮点击音效
- `sounds/scream.mp3` - 恐怖尖叫声效

然后取消script.js文件中相关代码的注释。

### 调整恐怖效果

您可以在script.js文件中修改以下参数来调整恐怖效果：
- 幽灵出现的频率和持续时间
- 血滴的大小和下落速度
- 屏幕闪烁的触发条件
- 惊吓效果的显示内容和持续时间
